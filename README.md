# Adry Cookies — Adry Silva Cookie Designer

Site de apresentação de bolachas de mel decoradas, com destaque para árvores de Natal. A identidade visual utiliza a logo original e as cores do app de estoque AdryCookies.

## Executar localmente

Requer Python 3. Na pasta do projeto:

```sh
python3 -m http.server 1570 --bind 127.0.0.1
```

Abra http://localhost:1570.

## Estrutura

- `index.html`: página, estilos responsivos e interação de contato.
- `logo-adry.png`: logo da marca, extraída do app existente.
- `arvore.svg`, `estrela.svg`, `presente.svg`: ilustrações de referência, não fotos dos produtos.

Site estático, sem instalação de dependências. Para hospedar, publique os arquivos desta pasta em uma hospedagem estática.
